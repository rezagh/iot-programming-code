# Data Analysis (Chapter 10)

Companion example for *Chapter 10: Data Analytics and Visualisation*.

- `sensor_data.csv` — 24 hours of simulated temperature readings (one per minute) with noise and a few glitch spikes.
- `generate_data.py` — regenerates the CSV (standard library only).
- `analysis.py` — the chapter's workflow: load, downsample, smooth, and plot.

Install dependencies: `pip install pandas matplotlib`
