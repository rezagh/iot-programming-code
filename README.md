# IoT Programming: Companion Code

Welcome to the official code repository for the book **"IoT Programming"**.

This repository contains the source code, wiring diagrams, and examples used throughout the book. It is designed to be a hands-on companion to your reading, allowing you to test, modify, and expand upon the projects discussed in the chapters.

## Structure

The repository is organized by platform to match the book's progression:

*   **`/arduino`**: Contains firmware sketches (`.ino`) for Arduino Uno and ESP32. This covers **Chapters 2, 3, 5, 6, and 13**.
    *   *Examples:* Blink, Traffic Light, WiFi Connection, MQTT Client.
*   **`/raspberrypi`**: Contains Python scripts, Flask web apps, and system configuration files. This covers **Chapters 4, 7, 8, 10, 11, and 13**.
    *   *Examples:* MQTT Broker setup, Sensor Datalogging, Dashboard, AI integration.

## How to Use This Repository

1.  **Clone the Repo:**
    ```bash
    git clone https://github.com/rezagh/iot-programming-code.git
    ```
2.  **Navigate:** Go to the folder corresponding to the chapter you are reading.
3.  **Experiment:** The code here is a starting point. Change variables, break things, and fix them. That is how you learn.

## Important Note

This is a **living repository**. While it aims to support the book, you may find differences or improvements in the code compared to the printed text. This is intentional to ensure the examples remain up-to-date with modern libraries and APIs.

Happy Coding!
